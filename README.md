# AI設備仕様コンシェルジュ (AI Equipment Specification Concierge)

## 概要

このプロジェクトは、顧客がウェブサイト上でAIチャットボットとの対話を通じて、自社が求める設備（工場の自動機・半自動機）の簡易的な仕様書（提案書）を自動生成できるツールです。

主な目的は以下の通りです。

*   設備仕様書の作成に不慣れな顧客でも、容易に初期検討を進められるようにする。
*   AIとの対話を通じて、顧客の潜在的なニーズや課題を明らかにする。
*   自動生成された簡易提案書をフックとして、営業リードを獲得し、その後の詳細ヒアリングや商談に繋げる。

## プロジェクト構成

*   **フロントエンド**: HTML, CSS, JavaScript (vanilla JS)
    *   `index.html`: サービス紹介ページ
    *   `hearing.html`: AIチャットインターフェース
    *   `result.html`: 簡易提案書表示ページ
    *   `thankyou.html`: 問い合わせ完了ページ
*   **バックエンド**: Python, Flask
    *   `app.py`: APIサーバー本体 (チャット処理、データベース連携)
    *   Gemini API: AIチャットボットの応答生成
    *   PostgreSQL: 会話ログ、顧客情報、提案内容の保存

## APIエンドポイント

主なAPIエンドポイントは以下の通りです。

*   `POST /api/chat`:
    *   フロントエンドからのユーザーメッセージを受け取り、Gemini APIを介してAIの応答を生成し返します。
    *   会話ログやAIによる抽出情報をデータベースに保存します。
*   `POST /api/contact`:
    *   提案書ページのお問い合わせフォームから送信された顧客情報をデータベースに保存します。

詳細なAPI仕様やシステムプロンプトについては、`BACKEND_HANDOVER.md` を参照してください。

## 環境構築と実行

詳細な環境構築手順については、[`SETUP_GUIDE.md`](SETUP_GUIDE.md) を参照してください。

手順の概要：
1.  リポジトリをクローン（またはファイル配置）。
2.  Python仮想環境を作成し有効化。
3.  必要なライブラリをインストール (`pip install -r requirements.txt`)。
4.  `.env` ファイルを作成し、`GOOGLE_API_KEY` と `DATABASE_URL` を設定。
5.  データベースを初期化 (`python init_db.py`)。
6.  バックエンドサーバーを起動 (`python app.py`)。
7.  ブラウザで `index.html` を開く。
